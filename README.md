# E-Cycle — GitHub Pages edition

Static responsive website built with HTML, CSS and JavaScript. No Flask, Python server, SQLite, database or backend.

## Publish on GitHub Pages
1. Create a GitHub repository, for example `e-cycle`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait for publishing. The site URL will look like `https://YOUR-USERNAME.github.io/e-cycle/`.

## Limitations
- Registration and admin status edits are a front-end demo only; browser localStorage is not a shared database.
- There is no secure admin login or multi-user storage.
- Collection centre entries are fictional demo placeholders. Confirm real local centre details before visiting.
- Chart.js and the hero background image use external CDNs/URLs and need internet access.
- Do not enter sensitive personal information.
